# TENNIS CLUB — студенческий теннисный клуб

Адаптивный двухстраничный сайт на **HTML5 + CSS3**. JavaScript и сторонние JS-библиотеки не используются.

## Запуск

1. Распакуйте архив целиком.
2. Откройте `index.html` в браузере или запустите локальный сервер из этой папки:
   - Python: `python -m http.server 8000`
   - затем откройте `http://localhost:8000`.
3. Вторая страница — `schedule.html` (ссылка есть в меню обеих страниц).

## Страницы и возможности

- `index.html` — hero-блок, бесшовная бегущая строка слева направо, описание клуба, статистика, 6 карточек мероприятий с разными фотографиями, форма, FAQ.
- `schedule.html` — 6 карточек событий с отдельными тематическими фотографиями, CSS-фильтр по категориям, поле поиска-заглушка, CSS-модальные окна по `:target`, FAQ.
- Переключатель светлой/тёмной темы реализован скрытым checkbox и CSS-переменными.
- Форма использует нативную HTML-валидацию (`required`, `type=email`, `minlength`) и отправку через почтовый клиент (`mailto:`). Для реальной серверной обработки потребуется отдельный backend, который в рамках задания не используется.
- Поиск — визуальная заглушка по ТЗ, без JS-функциональности.
- Изображения находятся в `assets/`; карточки событий используют разные фотографии (парная игра, подача, командное празднование, одиночный розыгрыш и другие теннисные сцены). Все изображения локальные, поэтому сайт работает офлайн (шрифт может подгружаться из Google Fonts при наличии интернета).
- Бегущая строка сделана на CSS: два одинаковых набора текста создают бесшовный цикл движения слева направо; при наведении движение приостанавливается, а при `prefers-reduced-motion` отключается.
